# Отклик — приложение опросов на Django

Типы вопросов: текст, один или несколько вариантов, картинки, ползунок.
Ответы сохраняются в SQLite. Результаты доступны сотрудникам.

Запуск в PowerShell (первый запуск после клонирования):
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py seed_demo
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py runserver
```
Откройте http://127.0.0.1:8000/. Панель управления: /admin/.
Создайте опрос, затем вопросы; откройте каждый вопрос для добавления вариантов и ссылок на картинки.
Для демонстрации используются локальные SVG. Настройки предназначены для локальной разработки.

## Админка и статистика

В разделе «Опросы» ссылка «Смотреть статистику» показывает распределение ответов, среднее значение ползунков и последние прохождения. «Пройденные опросы» содержит историю с фильтрами по опросу и дате; откройте запись для просмотра всех ответов.

Для тестов включите «Проверять правильность ответов» и отметьте правильные варианты в вопросах. Оцениваются одиночный, множественный выбор и картинки. Множественный выбор засчитывается только при точном совпадении набора. Вопросы без настроенного ключа не оцениваются. Для текста, аудио и ползунка ключ задаётся отдельно. Результат и текст ответа сохраняются при прохождении; старые ответы не переоцениваются. Прохождения анонимны.

## Интерактивные тесты и разбор ответов

`python manage.py seed_interactive` добавляет в оба демонстрационных теста картинки, оцениваемый ползунок и аудиозадание с сигналом Морзе. Повторный запуск не создаёт дубликаты. Локальный WAV-файл воспроизводится стандартным плеером браузера.

После отправки участник видит только подтверждение сохранения и общую плашку: долю успешных оценённых прохождений для тестов или количество прохождений для обычных опросов. Порог успеха задаётся в админке (по умолчанию 80%). Участники анонимны, поэтому доля относится к прохождениям, а не уникальным людям. Пустая статистика не показывается как 0%.

Все подробные ответы, правильные варианты, оценки и статистика находятся в админке. Старые ссылки на результаты перенаправляют сотрудников в админку; участникам подробные прохождения недоступны.

В админке для ползунка задаётся правильное число. Для текста и аудио допустимые расшифровки указываются по одной на строку; регистр, пунктуация и пробелы не учитываются. Правильные ответы и объяснения сохраняются вместе с ответом участника. Для старых прохождений, созданных до этого обновления, ключ не восстанавливается задним числом.

## Пазл с ползунком

В админке откройте «Вопросы» → «Добавить вопрос» и выберите тип «Пазл с ползунком». Загрузите свою картинку в блоке «Пазл с ползунком». Задайте горизонтальное положение цели (0–100), вертикальное положение и погрешность (по умолчанию ±3 пункта). Место фрагмента можно выбрать нажатием или перетаскиванием рамки прямо на картинке. Предпросмотр обновляется сразу, до сохранения. Числовые поля доступны для точной настройки и работы с клавиатуры.

Из одной картинки автоматически получается прямоугольный фрагмент (20% ширины и 30% высоты). Участник двигает его ползунком. Позиции 0 и 100 означают крайние положения фрагмента, а не координаты пикселей. Управление работает мышью, касанием и стрелками клавиатуры. Для движения картинки нужен JavaScript; библиотеки не используются.

В тесте сервер проверяет попадание в диапазон цели с учётом погрешности. В обычном опросе положение сохраняется без оценки. Подробный результат и ключ сохраняются в админке. Готовые изображения в проект не добавлялись: загрузите свои через форму. Файлы хранятся в `media/`, Pillow проверяет загруженное изображение. В режиме разработки Django раздаёт их автоматически.

## Создание опросов

В навигации сначала идут «Опросы», затем «Вопросы» и «Пройденные опросы». Новый опрос создаётся как черновик: сохраните название и описание, затем добавляйте вопросы кнопкой внутри редактора опроса. Каждый вопрос открывается в полной форме с настройками своего типа и вариантами ответов. После обычного сохранения вопроса вы вернётесь к опросу. Кнопка «Сохранить и добавить другой объект» сохраняет привязку к тому же опросу.

Редактор вопросов показывает настройки только выбранного типа. Для пазла загруженное изображение сразу появляется в визуальном редакторе; нажатие и перетаскивание рамки меняют координаты цели, а ползунок ниже позволяет проверить сборку. Файлы отправляются на сервер только при сохранении вопроса.

Кнопка «Открыть предпросмотр опроса» работает и для черновика, доступна сотрудникам с правом просмотра опроса и не сохраняет ответы. Проверив сохранённую версию, включите «Опубликован» в настройках опроса.

## Что хранится в репозитории

В Git включены исходный код, миграции, тесты и демонстрационные статические файлы. Локальная база с опросами и ответами (`db.sqlite3`), загруженные изображения (`media/`), окружение (`.venv/`), настройки IDE и папки `codex/`, `.codex/`, `config/` не публикуются.

При первом запуске Django автоматически создаёт локальный секретный ключ в `config/django_secret_key`. При необходимости его можно задать через переменную окружения `DJANGO_SECRET_KEY`. Ключи и пароли не нужно добавлять в Git.

Чтобы восстановить демонстрационные тесты на другой машине, выполните `python manage.py seed_interactive` после миграций. Загруженные вами изображения и реальные данные нужно переносить отдельно.
